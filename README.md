# IP Address Tracker

A lightweight frontend project for looking up and presenting IP address information in a clear, map-oriented interface.

## Overview

This project focuses on turning IP lookup data into an accessible user experience with a clean interface and responsive layout.

## Tech Stack

- Svelte
- TypeScript
- Vite
- SCSS

## What It Demonstrates

- Svelte component-based development
- Type-safe frontend implementation with TypeScript
- API-driven UI patterns
- Responsive interface development

## Getting Started

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL shown by Vite in your browser.

## Build

```bash
npm run build
npm run preview
```
